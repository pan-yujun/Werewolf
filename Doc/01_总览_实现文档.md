## 三、 环境配置与项目启动

1.  **依赖安装**：使用 pnpm 包管理器进行安装。
    ```bash
    pnpm install
    ```
2.  **开发服务器运行**（Webpack 编译模式）：
    ```bash
    pnpm dev
    ```
3.  **核心外部 API 密钥依赖 (配置于 `.env.local`)**：
    *   `ZENMUX_API_KEY` — 统一 LLM 决策路由密钥 (ZenMux 平台)
    *   `MINIMAX_API_KEY` / `MINIMAX_GROUP_ID` — 流式人物 TTS 声音合成接口密钥
    *   `NEXT_PUBLIC_SUPABASE_URL` / `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_DEFAULT_KEY` — 用户账号及游戏局历史云端同步库
